# ReadThatOut

ReadThatOut is a Chrome extension that reads web articles aloud with a natural AI voice and word-by-word highlighting. Speech runs on your device — page text is not uploaded.

**This repository is the public issue tracker.** The source code is private and is not published here.

## Send feedback or report a bug

[Open an issue](https://github.com/reejosamuel/read-that-out/issues/new/choose)

Please include:

- What you were doing
- What happened instead
- Chrome version and operating system
- The page URL, if reading failed (omit anything private)

## This is not an open-source project

Do not send pull requests or source code. Issues are the only thing this repo is for.
